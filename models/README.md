# Model directory

Model weights are not distributed in this public branch.

The paper used one fixed nine-label PhoBERT checkpoint for every compared condition. Its recorded SHA-256 is:

```text
d8e1ab2f6bc3d71480fffb6e487e5b63f36467a2d0a586585f871ce65b9d25f6
```

The retained artifacts do not establish that checkpoint's original training seed. Place an authorized compatible checkpoint in a gitignored local path and configure the pipeline accordingly.
